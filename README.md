# KOZENI

電卓のように金額を打ってカテゴリを押すだけの家計簿。スプシ「KOZENI__DB用」を DB にし、ブラウザ（PWA）は画面だけを持つ。

```
iPhone / PC のブラウザ（web/）
   │  端末内の未送信キュー（5秒の取り消し期間のあと、まとめて送る）
   │  POST（text/plain の JSON ＋ 合言葉）
   ▼
GAS ウェブアプリ（gas/Code.gs）  ← 毎月1日0時台に固定費を計上するトリガー
   ▼
スプシ（expenses / categories / fixed_costs / incomes / summary）
```

| 場所 | 中身 |
|---|---|
| `gas/Code.gs` | スプシに紐づける Apps Script。窓口は `add`・`addBatch`・`state`・`month`・`update`・`delete` |
| `web/index.html`・`app.js` | 画面の土台（入力・履歴・まとめのタブ、送信、設定） |
| `web/calc.js` | 電卓の入力（数字・00・+・⌫・C） |
| `web/store.js` | 端末内の保存（設定・前回の状態・未送信キュー・今月の月データ） |
| `web/month.js` | 履歴とまとめの計算（未送信分の上乗せ・割合・日ごとのまとめ・色） |
| `web/history.js` | 履歴画面と、記録を直す・消すシート |
| `web/summary.js` | まとめ画面（残り・円グラフ・固定費・カテゴリの詳細） |
| `web/api.js` | GAS の呼び出し |
| `web/sw.js` | Service Worker。画面のファイルを端末に置き、電波がなくても開ける |
| `dev/` | 手元確認用。GAS を模擬スプシの上で動かすテスト・サーバ・サンプルデータ・PWA 確認 |

## 使い方

**入力**：金額を打ってカテゴリを押す（`+` で足し算も可）。その場で記録され、5秒以内なら「取り消す」で消せる。5秒たつと裏でスプシに送る。電波がないときは端末に残り、右上に「未送信 n件」と出る。

**履歴**：月ごとの記録を日ごとに並べる。行を押すと金額・カテゴリ・日時を直せる。削除は2回押しで確定。送信待ちの記録は送り終わるまで直せない。

**まとめ**：
- この月の残り ＝ 繰越 ＋ 収入 − 支出（固定費を含む）。繰越は開始月が summary の「初期繰越」、以降は前の月の残り
- 円グラフは「使った額」（固定費を除く）のカテゴリ別。多い順で「その他」は最後。真ん中に先月との差
- カテゴリを押すと、6か月の推移とその月の記録
- 固定費は円グラフの外に1行で出し、押すと内訳

**PC**：同じ URL をブラウザで開けば同じ画面が使える。スプシの `summary` シートにも月ごとの表（収入・支出・固定費・変動費・繰越・残高・カテゴリ別）が数式で出る。

## スプシの決まりごと

- `expenses`：アプリと固定費トリガーが書く。手で直すならセルの値を書き換えるだけにし、行の挿入や列の入れ替えはしない（修正・削除はアプリの履歴からが安全）
- `categories`：並び順（order）と使うか（active）を手で編集する。**カテゴリを足したり名前を変えたりしたら `setupPhase3` を実行し直す**（summary のカテゴリ別の列が作り直される）
- `fixed_costs`：毎月1日0時台に active のものが `expenses` に「固定費」として入る。値段が変わったら翌月から反映（今月分は履歴から直す）
- `incomes`：A 列は書式なしテキストで `2026-11` の形。仕送り・バイトを1行ずつ
- `summary`：1行目「初期繰越」、2行目「開始月」だけ手で入れる。4行目から下は `setupPhase3` が作る数式の表なので触らない

## 手元で確かめる

```bash
node --test dev/test.mjs dev/web.test.mjs dev/phase3.test.mjs dev/month.test.mjs
```

```bash
SEED=1 DELAY_MS=800 node dev/server.mjs
```

`http://localhost:8788` を開き、設定に URL `http://localhost:8788/api`、合言葉 `dev-token`（`dev/fixture.json`）を入れる。

- `SEED=1` で開始月を5か月前にした半年分のサンプル（支出・固定費・収入）が入る
- `DELAY_MS` で GAS の遅さを真似る（実測は 2.5〜3.5秒）
- `curl 'localhost:8788/api/_offline?on=1'` で通信断、`on=0` で戻る
- 模擬スプシの中身は `http://localhost:8788/api/_sheets`
- `node dev/pwa-check.mjs [URL]` で、ヘッドレス Chrome に Service Worker が入り、電波なしでも開けるかを確かめる（Claude デスクトップアプリ内のブラウザは Service Worker を登録できないため）

## 本番に出す手順

GAS を先に直し、そのあと画面を出す。

1. **GAS のコード**：Apps Script エディタで `コード.gs` を `gas/Code.gs` の中身で置き換えて保存。
2. **Phase 3 の準備（初回とカテゴリを変えたとき）**：関数の選択で `setupPhase3` を選んで実行。
   - 権限の確認が出たら許可する（固定費のトリガーを作るため、Phase 1 より権限が1つ増える）
   - `expenses` に `memo` 列ができ、`summary` の4行目から下に月ごとの表ができ、毎月1日0時台のトリガーが1つ入る
   - `summary` の開始月が空なら**来月**を入れる。11月に入ってから初めて実行するときは、先に A2 に「開始月」、B2 に `2026-11`（書式なしテキスト）を入れておく
   - 開始月に入っていれば、今月の固定費もその場で計上する（何度実行しても二重にならない）
3. **公開し直す**：「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」→「デプロイ」。**「新しいデプロイ」は使わない**（URL が変わる）。`setupToken` も実行しない。
4. **画面**：main に push すると GitHub Actions が `web/` を Pages に公開する。
5. **iPhone**：ホーム画面の KOZENI を開く。更新は次に開いたときに反映される（反映されないときは一度アプリを完全に閉じて開き直す）。

## はじめてつなぐとき（Phase 1 の手順）

1. スプシ「KOZENI__DB用」で「拡張機能」→「Apps Script」。プロジェクト名を `KOZENI` にする。
2. 「プロジェクトの設定」で「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェック。
3. `コード.gs` を `gas/Code.gs`、`appsscript.json` を `gas/appsscript.json` で置き換えて保存。
4. `setupToken` を1回だけ実行し、実行ログの64文字（合言葉）を控える。「Google はこのアプリを確認していません」と出たら「詳細」→「KOZENI（安全ではないページ）に移動」→「許可」。
5. 「デプロイ」→「新しいデプロイ」→ ウェブアプリ。実行ユーザー：自分、アクセスできるユーザー：全員。出てきた `…/exec` の URL を控える。
6. iPhone で Pages を開いて「ホーム画面に追加」し、**ホーム画面から開いた状態で**設定に URL と合言葉を入れる（Safari のタブとは保存場所が別）。

## うまくいかないとき

| 表示 | 原因と直し方 |
|---|---|
| 合言葉が違います | 実行ログの64文字をもう一度コピーして設定に入れ直す |
| 送信できません（unknown_action）／読み込めませんでした（unknown_action） | GAS が古い。「本番に出す手順」の 1〜3 をやる |
| missing_sheet:… / missing_column:… | シート名か見出しが変わっている |
| 「◯件を記録できませんでした（…unknown_category）」 | そのカテゴリの active が外れている。記録は捨てられるので入れ直す |
| まとめの残りが「—」 | その月が summary の開始月より前。開始月を確かめる |
| summary のカテゴリ別の列が足りない・名前が古い | `setupPhase3` を実行し直す |
| 固定費が入っていない | 開始月より前か、トリガーがまだ動いていない。`addFixedCosts` を手で実行してもよい（二重にならない） |
| つながりませんでした | アクセスできるユーザーが「全員」になっていない、または URL が `/exec` で終わっていない |
